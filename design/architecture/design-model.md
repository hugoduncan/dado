# Progress

- Describe (situation)
- Diagnose (possible problems)
- Delimit (the problem to be solved)
- Direction (strategy, approach)
- Design (tactics, implementation plan)
- Dev (implementation)

## Describe

One paragraph:

Situation/Context
Bug/failure reports
Feature requests

don't describe the problem, accept as fact assertions that imply the problem

## Diagnose

bug/deffect/featur

Bugs:  symptom -> hypotheses (pl) -> likely problem
use logic and scientific method

Features:  feature -> user's intention/objective
what is in the way?

Problem Statement: Succinct statement of unmet user objectives and causes
not remedy/solution/feature

evolves over time.  KEEPS YOU ON-TRACK.
