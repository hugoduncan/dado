# Project Document Metadata

Each document has metadata associated with it.

## Metadata Keys

### Specificity

The level of specificity the document uses.

### Precision

An estimate for the precision of the document.

### Embedding vector

An embedding vector for the document's content.


## Metadata Storage

The metadata can be stored in sidecar edn files.

A sidecar file on a directory applies to all files under that directory.
